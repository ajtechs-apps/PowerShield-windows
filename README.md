PowerShield v1.0.0 — Production Release (x64)

Next-Generation Windows System Diagnostics, Kernel-Grade Optimization & Privacy Suite
Crafted with WinUI 3, Windows App SDK 1.6, and .NET 8 for high performance with zero bloat.

🚀 Highlights & Features
⚡ Smart System Optimization & Cleaning
Deep Clean Engine: Automated discovery and multi-level purge of Windows temporary data, shader caches, crash dumps, log accumulation, and thumbnail databases.
RAM Optimizer & Standby Purge: Real-time memory pressure diagnostics with single-click working set reduction and kernel standby memory reclamation.
Hardware-Accelerated Game Boost: One-click gaming mode that disables latency-inducing telemetry hooks, parks idle background tasks, and optimizes processor core affinity.
🔋 Battery Health & Power Orchestration
Hardware Degradation Diagnostics: Direct ACPI and WMI power rail telemetry revealing true cell cycle count, factory design capacity, current charge capacity, and degradation wear percentage.
Instant Power Scheme Switching: Switch between Balanced, High Performance, Power Saver, and Workstation Zero-Latency Ultimate Performance profiles without opening legacy Control Panel applets.
Battery & Sleep Diagnostic Tools: One-click generation of native Windows HTML Battery Reports, 5-second Energy Audits, and Sleep Study traces.
🔒 Telemetry Hardening & Privacy Shield
Diagnostic Data Suppression: Configurable telemetry suppression levels (Minimal, Balanced, Maximum Privacy) with reversible staging.
Service Hardening: Safeguard background network traffic by disabling non-essential diagnostic trackers and advertising identifiers while keeping Windows Update intact.
🎛️ Diagnostics, Repair & System Management
Advanced Task & Startup Manager: Deep visibility into process trees, autostart programs, and scheduled task startup impact scores.
Windows Component Repair: Integrated DISM, SFC (sfc /scannow), and component store health scans with live progress and automated repair execution.
Network & DNS Suite: Network adapter performance monitoring, socket diagnostics, DNS flush, and DoH (DNS-over-HTTPS) encrypted resolver status.
Modern Uninstaller: Clean batch removal of desktop applications and provisioned Windows UWP/AppX packages with deep registry leftover scanning.
🪟 Desktop Performance Floating Widget
Always-on-Top Floating Widget: Compact performance pill displaying live CPU usage, RAM consumption, and network throughput with a tactile single-click Boost button.

📋 System Requirements
Operating System: Windows 11 (all versions) or Windows 10 (version 19041+) 64-bit
Architecture: x64 (AMD64 / Intel 64)
Privileges: Standard user (prompts for UAC elevation only when performing deep system repairs or kernel tweaks)
